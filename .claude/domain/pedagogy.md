## Estructura curricular — 5 Tracks

| Track | Carpeta | Contenido | Lecciones aprox. |

## Progresión obligatoria
Track 00 → Track 01 → Track 02 (paralelo o posterior) → Track 03 → Track 04.
**No saltarse Track 00** — los fundamentos de párrafo son prerequisito para todo lo demás.

## Principios pedagógicos del curso

1. **Scaffolding**: Cada lección sigue Theory → Modeled example → Guided practice → Independent practice → Essay task
2. **Feedback formativo**: Los agentes no califican — guían
3. **Autonomía progresiva**: Track 00 es altamente guiado; Track 04 es evaluación autónoma
4. **Peer learning**: Track 03 es obligatorio para desarrollar pensamiento crítico
5. **Autenticidad**: Los temas de ensayo son relevantes para Ecuador y ULEAM

## Lo que Claude debe saber para no romper la progresión

- Si se edita contenido de Track 00, verificar que no asuma conocimiento de Track 01
- Los módulos `L-001` (Argumentative Essay) y `L-002` (Chain Essay) están marcados como **coming soon** — no están implementados aún
- Los módulos de Track 04 son evaluaciones — no deben revelar respuestas correctas en el HTML

## Tono de comunicación con estudiantes (para todos los agentes)
- Cálido pero honesto — no condescendiente
- Siempre en español con el estudiante
- Usar inglés solo para ejemplos de escritura correcta o citas del texto
- Reforzar logros reales antes de señalar brechas
